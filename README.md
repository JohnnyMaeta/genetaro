# 和文ワープロ Web（Wabun Word）

## これは何か

Webブラウザだけで軽快に動く、縦書き・原稿用紙・文書スタイル・教材プリント作成対応の日本語ワープロです。`index.html` 1枚で完結します。
日本の伝統的なワープロの作法（縦書き、原稿用紙、字数×行数指定、ふりがな、傍点、罫線表、ESCメニュー、ファンクションキーバー、シート管理）を、Web標準技術（HTML5/CSS3/JavaScript）で再現したオープンなWebアプリケーションです。

## 使い方

`index.html` をブラウザで開くだけです。サーバーもビルドも不要です。

- **GitHub Pages**: 公開リポジトリに配置するだけで即座にWebサービスとして利用可能
- **オフライン動作**: USBやGoogleドライブ等で `index.html` を配布するだけで、インターネット接続がない環境でも動作
- **端末を選ばない**: Windows、Mac、Chromebook、iPad等の各種ブラウザに対応

## 主な機能

| 機能 | 実装 |
|---|---|
| **縦書き／横書き** | F5 でワンクリック切替。CSS の `writing-mode: vertical-rl` |
| **原稿用紙** | F6。20×20字詰めのマス目をリアルタイム描画 |
| **文書スタイル（字数×行数）** | 右パレット「文書」。用紙（A4/B5/A5/B4）・余白・字数・行数から字送り・行送りを自動計算 |
| **教材・テスト作成** | 右パレット「教材」。氏名欄、得点枠、大問・設問記号、短文/記述解答枠、字数指定マス、国語・理科テストテンプレート |
| **ふりがな（ルビ）** | F7。HTML5 `<ruby>` タグを簡単付与 |
| **傍点・縦中横・囲み文字** | `text-emphasis` / `text-combine-upright` / 囲み枠 / マーカー |
| **罫線（表）** | F8。HTML `<table>` の作成、行・列の追加・削除 |
| **ESCメニュー** | Escキーでメニューバーへフォーカス。←→↓Enterキーでキーボード操作 |
| **ファンクションキーバー** | 画面下に F1〜F12 バーを常駐（画面タッチ・クリック対応） |
| **シート管理** | 画面下のタブで複数文書を並行編集。シートごとに縦書き/横書きやスタイルを保持 |
| **ジャンプパレット** | 見出し1〜3および改ページの一覧から瞬時に移動 |
| **文書校正** | 二重助詞・句読点連続・ら抜き・二重敬語・長文・表記ゆれ・AI臭い表現などをチェック |
| **文字数カウント** | F2。原稿用紙換算枚数つき |
| **保存・書き出し** | localStorage自動保存。`.wbw`（独自JSON）・テキスト・HTML で書き出し |
| **印刷** | Ctrl+P。A4/B5用紙サイズを `@page` に反映し、余計なUIを除外してジャストサイズ印刷 |

## 割り切り・留意事項

- 日本語入力はブラウザ（OS標準）のIMEを使用します。
- ページ分割は画面上の「目安線」表示です。確実に改ページしたい箇所には手動で改ページ（Ctrl+Enter）を挿入してください。
- F11・F12等のキーはブラウザ固有のショートカットと競合する場合があります。その際は画面下のファンクションキーバーをクリックしてください。

## 中身の構造

```
1-210    head・CSS（配色トークン、縦書き、原稿用紙グリッド、パレット、印刷）
211-425  HTML本体（タイトル行・メニュー・ツールバー・編集面・右パレット・シート・ステータス・Fキーバー・ダイアログ）
426-     JS
  MENUS / FKEYS   … メニューとファンクションキーの定義（ここを直せばUIが変わる）
  applyStyle()    … 文書スタイル→CSS変数（--cell/--pitch/--lp）に変換
  save/restore    … localStorage 保存・復元、.jtdg 読み書き、sanitizeHtml
  KOUSEI_RULES    … 校正ルール（正規表現の配列。追加はここ）
  run(cmd)        … 全コマンドの入口
```
